Anticipatory Action — Fiji Tropical Cyclones

Trigger monitoring for the Fiji National Anticipatory Action Framework for Tropical Cyclones (2025–2027). Every RSMC Nadi forecast is checked for the number of people in the 64-knot wind zone, and satellite rainfall is checked daily.
